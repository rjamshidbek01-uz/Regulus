# Regulus — project handoff

Duolingo-style web app that teaches **English to Uzbek speakers, in Uzbek**. Live: https://regulus-jamshidbek1.vercel.app

## Stack
- Next.js 15 (App Router, JavaScript), React 19, Zod, `@node-rs/argon2`, `@neondatabase/serverless`
- DB: Neon Postgres (project `curly-mud-44522540`, branch `br-rough-sun-ar8zduan`, db `neondb`)
- Hosting: Vercel (team `team_2sRe5Y7NANiASTDlghF266DX`, project `regulus` = `prj_laK8BeoOBdNgf8FM5QgH269Twnnp`)
- AI: Google Gemini (preferred, `GEMINI_API_KEY`) with Groq fallback (`GROQ_API_KEY`); mail: Brevo (`BREVO_API_KEY`, `MAIL_FROM`) or Resend

## Environment variables (names only — set them in Vercel/.env, never commit values)
DATABASE_URL, AUTH_SECRET, APP_URL, GROQ_API_KEY, GEMINI_API_KEY (optional), BREVO_API_KEY, MAIL_FROM, optional GROQ_MODEL / GEMINI_MODEL, optional COURSES_ENABLED (comma-separated course codes to launch, e.g. `ru,de`)

## Hard rules / decisions
- All Uzbek text uses the **Turkish-style Latin alphabet**: o'→ö, g'→ğ, sh→ş, ch→ç, capital I at word start → İ (e.g. Luğatim, İngliz tili). Say "ingliz tili", never "inglizça"; formal register ("siz").
- AI answers: full explanation first, then "Misollar:" with `*English* — Uzbek`; no parentheses translations; server converts output to the Turkish-style alphabet (`toTurk` in `app/api/ai/route.js`).
- Translations for beginners: every lesson starts with an "intro" card showing all 8 new words (translation + audio); after every answered exercise the footer shows the word/sentence with its translation. Hints (dictionary form) appear on hover, focus or tap, only on the QUESTION text — target-language text gets Uzbek hints, Uzbek sentences to translate get target-language hints (with simple suffix matching and fixed pronoun hints) — never on answer choices, chips or pairs (`lib/glossary.js`).
- Lives: 5 per day (reset at midnight Asia/Tashkent), −1 per mistake (server-side `/api/lives/lose`); at 0 lives lessons are blocked; chapter practice test (20 questions, ≤3 mistakes = 85%) gives +3 lives.
- Streak counts any active day (visiting while logged in); computed in `currentUser()` in `lib/auth.js`.
- Header numbers (hearts/streak/xp) are a client component refreshed via `/api/me` + `regulus:refresh` event, because the root layout is not re-rendered on soft navigation.
- Auth: argon2id, httpOnly session cookie `sid`, rate limits in `rate_limits` table, math captcha + honeypot, email verification only when a mail key exists.

## Design (night-sky theme + mascot)
- Mascot: **Regi**, a lion cub with a crown and star-tipped tail (`app/components/Regi.js`, pure SVG; moods: happy, wave, cheer, sad, think, sleep, shy). Shown on landing, lesson path, player, auth forms, tutor, empty states.
- One stylesheet: `app/globals.css` (tokens at the top; dark sky background, white chunky cards, 3D pressable buttons). Fonts are self-hosted via `@fontsource-variable/fredoka` (display) and `nunito` (body); CSP allows only `font-src 'self'`.
- `app/components/Fx.js`: `Tilt` (pointer 3D), `Confetti`, `sfx` (WebAudio sounds, mute stored in localStorage). `Icon.js`: inline icons. `Nav.js`: top links (≥1024px) and bottom tab bar (below).
- All motion is transform/opacity and is disabled under `prefers-reduced-motion`. The player hides the site header/footer.

## Structure
- `lib/curriculum.js` — the English course: the first 15 chapters + `lib/units/{a1,a2,b1,b2}.js`, put in level order by `ORDER` (A1 1–20, A2 21–40, B1 41–60, B2 61–80; 240 lessons, 8 words + 6 sentences each). Lesson ids are positional and stored in `lesson_progress`, so **once real learners exist, only add chapters at the end** (or migrate `lesson_progress`). Exercises are generated by `lib/engine.js` (4 parts: Sözlar, Eşitiş, Tarjima, Takrorlaş).
- Learn UI: `/learn` = mission card + "Yulduzlar xaritasi" (4 galaxies of 20 chapters, `WORLDS` in curriculum.js; `MapView`, `Planet`); `/learn/bolim/[n]` = chapter page (Regi tip, `Constellation` of 3 lessons + test, word previews with audio, lesson buttons).
- `lib/practice.js`, `lib/review.js`, `lib/glossary.js`, `lib/mail.js`, `lib/auth.js`, `lib/security.js`
- `app/components/Player.js` — the lesson/practice/review player
- Leaderboard groups of 200 (`users.group_no`), About page with creators/tutorial, footer in `app/layout.js`

## Languages (multi-course)
- Registry: `lib/courses/index.js` — en (live) plus ru, de, fr, tr, ar, it (built, **hidden**). Each course = `makeCourse()` from `lib/engine.js` with name, speech voice (`ru-RU`...), text direction (`ar` is rtl) and chapters in `lib/courses/<code>.js` (same format as English: `w: "Target=Özbekça"`, `s: "Özbekça=Target"`). Each new course has 1 starter chapter so far.
- Visibility: a course is shown if its code is in env `COURSES_ENABLED` (e.g. `ru,de`) or the user has `users.role = 'admin'` (preview). **Launching a language = add its code to COURSES_ENABLED in Vercel.** Regular users never see hidden courses.
- The user's current course is `users.course` (switch on `/courses`, API `/api/course`); `courseFor(user)` picks it everywhere (map, chapters, lessons, tests, review, dictionary, AI tutor). Lives, points, streak and leaderboard are shared across courses.
- Alphabet pages for non-Latin scripts: `/alphabet` (letters, sounds, examples, tap to hear; Arabic also shows start/middle/end forms and vowel marks) and `/alphabet/[group]` (practice, no lives, nothing saved). Data: `lib/courses/alphabet-ru.js`, `alphabet-ar.js`.
- Check content before committing: `node --no-warnings scripts/validate-content.mjs` (all courses: counts, Uzbek spelling, target-language letters, duplicate meanings, exercise generation).
- DB: `db/migrations/002_courses.sql` adds a `course` column to users, lesson_progress and dictionary (step 1, additive) and switches the primary keys to include it (step 2 — run after the course-aware code is deployed; required before a second course goes live).

## Database tables
users(id, email, nickname, password_hash, email_verified, xp, streak, last_active, hearts, hearts_day, role, group_no, course, created_at), sessions, email_tokens, rate_limits, lesson_progress(user_id, course, lesson_id, score, completed_at), dictionary(user_id, course, word_en [= target-language word], word_uz, example_en, example_uz, correct_count, wrong_count, learned_at, next_review). (units/lessons/exercises tables exist but are unused; content lives in code.)
